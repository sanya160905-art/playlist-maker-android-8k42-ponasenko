# playlist-maker-android--
Учебный проект по созданию мобильного приложения

## Требования

- Android Studio Otter 2 Feature Drop 2025.2.2 Patch 1
- JDK 11 (через Android Studio)
- Android Gradle Plugin: см. корневой `build.gradle` проекта
- minSdk: 29
- targetSdk: 36
- compileSdk: 36

## Как запустить

1. Склонировать репозиторий:
   git clone <URL_репозитория>

2. Открыть папку проекта в Android Studio:
   File → Open… → выбрать корень проекта.

3. Дождаться синхронизации Gradle (пока исчезнет бегунок в статус‑баре).

4. Подключить устройство или запустить эмулятор.

5. В Android Studio выбрать конфигурацию `app` и нажать Run (зелёная кнопка).

### Sprint 8
- **Задача 1**: Многопоточность и debounce поиска
    - В SearchViewModel реализован автоматический поиск с задержкой 1 секунда через `debounce` + `distinctUntilChanged` на основе `MutableStateFlow`
    - При очистке поля поиск сбрасывается мгновенно без ожидания debounce
    - Старый ручной вызов поиска заменён на реактивный подход через `updateQuery()`

- **Задача 2**: История поиска
    - Создан `DatabaseMock` — хранилище данных в памяти (история, треки, плейлисты)
    - Реализованы интерфейс `SearchHistoryRepository` и его имплементация `SearchHistoryRepositoryImpl`
    - История хранит максимум 5 треков без дублей, новые треки добавляются наверх
    - В `SearchState` добавлено состояние `History` для отображения истории поиска
    - История показывается только при фокусе на поле поиска с пустым текстом
    - Поле поиска и блок истории визуально объединены в единый компонент

- **Задача 3**: Экран деталей трека
    - Создан `TrackDetailScreen` с информацией о треке и кнопками действий
    - Кнопка "Избранное" переключает состояние с визуальным отображением
    - Кнопка "В плейлист" открывает `ModalBottomSheet` с выбором плейлиста
    - Настроена навигация из поиска и истории на экран деталей трека

- **Задача 4**: Экран создания плейлиста
    - Создан `CreatePlaylistScreen` с полями названия и описания
    - Кнопка "Создать" активируется только при заполненном названии
    - Настроена навигация на экран создания из BottomSheet плейлистов

### Sprint 9
- **Задача 1**: Реализация настоящего поиска через iTunes Search API
    - Подключены библиотеки `Retrofit` и `Gson` для работы с сетью
    - Добавлено разрешение `INTERNET` в `AndroidManifest.xml`
    - Создан `ITunesApiService` — интерфейс Retrofit для поискового запроса к iTunes API
    - `TrackDto` и `TracksSearchResponse` обновлены под реальную структуру ответа сервера
    - Моковый класс `Storage` удалён, `RetrofitNetworkClient` теперь выполняет настоящие сетевые запросы
    - `TracksRepository` возвращает `Result<List<Track>>`, что позволяет различать пустой результат и ошибку сервера
    - Реализована кнопка "Обновить" для повторного запроса при ошибке сети
    - Подключена библиотека `Coil` для отображения обложек треков (`artworkUrl`)

- **Задача 2**: Реализация экрана плейлиста

    - Реализованы `PlaylistsRepository` и `PlaylistsRepositoryImpl` на основе `DatabaseMock`
    - Создан `PlaylistViewModel`, получающий плейлист по id через `Flow`
    - Создан `PlaylistScreen` с отображением обложки, названия, описания и списка треков
    - Список плейлистов на экране `PlaylistsScreen` подключён к моковым данным
    - Настроена навигация с передачей аргумента `playlistId` через `NavType.LongType`
    - Реализован полный путь навигации: список плейлистов → плейлист → детали трека
