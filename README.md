# playlist-maker-android--
Учебный проект по созданию мобильного приложения

## Список изменений

### Sprint 3
- **Задача 1**: Главный экран
    - Создан экран на Compose согласно макету Figma
    - Реализованы кнопки с обработкой нажатия через Toast

- **Задача 2**: Навигация между экранами
    - Созданы классы SearchActivity и SettingsActivity
    - Добавлены переходы по нажатию кнопок
    - Toast-сообщения заменены на реальную навигацию

### Sprint 4
- **Задача 1**: Вёрстка экрана поиска
    - Реализован экран SearchScreen на Compose по макету Figma
    - Добавлено текстовое поле с иконками лупы и "х"
    - Реализована логика очистки поискового запроса
    - Заготовка под будущую логику поиска

- **Задача 2**: Вёрстка экрана настроек
    - Реализован экран SettingsScreen по макету Figma
    - Кнопка "Поделиться приложением" открывает диалог шеринга
    - Кнопка "Написать разработчикам" открывает почтовый клиент
    - Кнопка "Пользовательское соглашение" открывает браузер с офертой
    - Все тексты вынесены в strings.xml
    - Используются Intent для взаимодействия с другими приложениями
